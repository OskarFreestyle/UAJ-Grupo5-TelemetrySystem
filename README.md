# Telemetry System

C++ telemetry tracker for game analytics, built by a team of five for the *Usabilidad y Análisis de Juegos* course at
Universidad Complutense de Madrid.

It was used to instrument **DOME**, a C++ / SDL survival game → [UAJ-Grupo5-InstrumentalizedGame](https://github.com/OskarFreestyle/UAJ-Grupo5-InstrumentalizedGame).

## Features

- **Typed events** for sessions, player position, actions, crafting, raids and item use, all derived from a common
  `TrackerEvent` and created through a factory.
- **Recurring events** sampled at a configurable interval (for example, player position).
- **JSON configuration** decides which events are tracked (bitmask), the queue size, the flush interval and the output
  formats.
- **Bounded memory:** events are buffered in a circular queue that drops the oldest entry when full, and the queue is
  flushed periodically and on shutdown.
- **Pluggable serializers and persistence:** JSON and CSV serializers behind `ISerializer`, and file persistence behind
  `IPersistence`, with one folder per session.
- **Anonymous session IDs** generated by hashing the start time with SHA-256.

## Usage

```cpp
#include "Tracker.h"

Tracker::Instance();                                    // reads the configuration and opens the session

// game loop
Tracker::Update(deltaTime);                             // drives the flush timer and recurring events
Tracker::Instance()->trackEvent(Tracker::createRaidSelectedEvent());

Tracker::End();                                         // flushes pending events and releases the tracker
```

## Building

Open `Tracker/Tracker.sln` in Visual Studio (Windows). The only dependency is [nlohmann/json](https://github.com/nlohmann/json),
which is included under `Tracker/dependencies/`. `TrackerTest.cpp` is a small test program.
